# Changelog

## 0.1.0

- Add styled terminal logging built from Chirp spans, with independent verbosity and plain file/JSON messages.
- Reuse Chirp span transformers and support custom spans through fresh-tree builders.
- Add text, confirmation, selection, multiselection, password, number, and asynchronous search prompts.
- Add shared progress displays with spinner, bar, counter, percentage, and static appearances.
- Add injectable terminal I/O, plain/noninteractive modes, input cancellation, and coordinated screen redraws.
